Notes:

- `CPU Core #1..#12` are logical processors (SMT threads), not physical cores.
- The `Core #N (Effective)` clock sensors report near-zero values at idle

- Without PawnIO, load still works but temperature and package power report 0.
  vitals treats 0 °C / 0 W as unavailable instead of showing a fake value.

## Disk and network throughput

These are not LHM sensors.

- Disk: `IOCTL_DISK_PERFORMANCE` on per-volume handles (`\\.\C:`, `\\.\D:`, …),
  summed across fixed volumes. On this machine the same IOCTL on
  `\\.\PhysicalDriveN` returns frozen counters, which is why vitals uses volumes.
  Requires elevation; unelevated runs show `0 B/s`.
- Network: `NetworkInterface.GetIPStatistics()` deltas, summed over adapters
  that are up and of type Ethernet or 802.11.
- Memory: `GlobalMemoryStatusEx` plus `GetPerformanceInfo` for commit and cache.

## Reproducing this dump

```powershell
vitals sensors            # human-readable table
vitals sensors --json     # machine-readable array of readings
```

When reporting a sensor bug, include the `vitals sensors --json` output and
your board, CPU and GPU model. New hardware maps belong in `docs/sensors/`.
